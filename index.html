État des services

Limites connues

Les applications tierces peuvent bloquer l'affichage en iframe. Le bouton « Ouvrir » les lance dans un nouvel onglet. Le téléchargement d'une application native dépend du système et du site officiel : Verox ne peut pas installer silencieusement un logiciel Windows ou Android depuis un navigateur.
